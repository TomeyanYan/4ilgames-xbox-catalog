# 4ILGAMES — каталог Xbox

Автоматическое копирование каталога с https://telegra.ph/Spisok-igr-1-12-14-3 и конвертация цен из RUB в BYN по официальному курсу НБРБ **без наценки**. Обновление ежедневно в **10:15 по Минску** или вручную.

## Настройка

1. Загрузите файлы этого архива в корень GitHub-репозитория `TomeyanYan/4ilgames-xbox-catalog`. Сохраните вложенную папку `.github/workflows/`.
2. Создайте аккаунт Telegraph API: откройте `https://api.telegra.ph/createAccount?short_name=4ILGAMES&author_name=4ILGAMES` — ответ содержит `access_token`. Не делитесь токеном.
3. В GitHub откройте **Settings → Secrets and variables → Actions → New repository secret**. Имя: `TELEGRAPH_TOKEN`, значение: ваш `access_token`.
4. Откройте **Actions → Sync Xbox catalog to Telegraph → Run workflow**.
5. После успешного запуска появится файл `state.json`. Значение `index` в нём — адрес главной страницы: `https://telegra.ph/ЗНАЧЕНИЕ_INDEX`.

## Важно

- Репозиторий публичный, поэтому никогда не добавляйте токен в файлы или сообщения.
- Скрипт не публикует каталог, если источник или курс недоступны, либо обнаружено подозрительно мало записей/цен.
- При частичной ошибке публикации некоторые разделы могут обновиться раньше остальных. Повторный запуск восстановит согласованность.
- Скрипт создаёт отдельные страницы по размеру и главную страницу со ссылками. Удалённые из исходника страницы остаются доступными по старым ссылкам, но исчезают из оглавления.
- Скрипт копирует содержание стороннего списка. Убедитесь, что у вас есть право на его перепубликацию.
- Автоматический запуск GitHub Actions может немного задерживаться; время 10:15 ориентировочное.
